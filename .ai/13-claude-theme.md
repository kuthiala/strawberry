# 13. Claude Theme

> Audience: anyone changing colours, stylesheets, the sidebar painting, or the Appearance settings page.

## 13.1 How it's applied

Setting `Appearance/theme` = `claude` (default) or `classic`, chosen in Settings → Appearance → Theme.
`main.cpp` calls `ClaudeTheme::Apply()` right after the resources are initialised (it needs `:/style/claude.css`). Three layers, all in `src/core/claudetheme.cpp`:

1. **Fusion style.** The native macOS style draws native controls that ignore the palette and most of the stylesheet, so nothing can look consistent on top of it.
2. **QPalette** from the design tokens (`ClaudeTheme::LightColors()` / `DarkColors()`). Selections (`Highlight`) are a soft accent tint with normal text (`HighlightedText` = text); the strong accent is `QPalette::Accent`, `Link`, `BrightText`.
3. **Application stylesheet** `data/style/claude.css`, with `{{token}}` placeholders (`{{window}}`, `{{accent}}`, `{{scheme}}` = `light`/`dark`, …) filled in by `ClaudeTheme::StyleSheet()`. A warning is logged if a placeholder is left over. Add new tokens to both the `Colors` struct and the token list in `StyleSheet()`.

Light/dark: dark when the "Dark mode" appearance checkbox is on, otherwise it follows `QStyleHints::colorScheme()` and re-applies live on `colorSchemeChanged`.

## 13.2 Custom painted widgets

Stylesheets can't reach widgets that paint themselves; those check `ClaudeTheme::IsActive()` and read `ClaudeTheme::colors()`:
- `FancyTabWidget::paintEvent` — flat `sidebar` colour plus a hairline instead of the gradient.
- `FancyTabBar::paintEvent` — selected tab is a rounded `selected` pill with a small accent mark, hover a `hover` pill, text without drop shadows.
- `DeviceSyncProgressModel` status icons use the same hues as constants.

## 13.3 Don'ts (each breaks something)

- **No `QSlider` rules** in `claude.css`: a stylesheet rule replaces the slider's style, which kills the moodbar / waveform proxy styles on the track slider.
- **No background on plain `QWidget`**: it paints over the playlist background image, the context view and the analyzer.
- **No SVG in the stylesheet**: the macOS deps don't ship the Qt SVG image plugin (`plugins/imageformats` has no `libqsvg`), `url(...svg)` renders nothing. Use PNG with an `@2x` variant (`data/style/claude/*.png`, generated by `data/style/claude/generate-icons.py`; regenerate rather than hand-edit).
- Every new resource must be listed in `data/data.qrc`.
- `StyleSheetLoader` (`src/core/stylesheetloader.cpp`) substitutes `%palette-<Role>` in **widget** stylesheets (e.g. `data/style/strawberry.css` on the main window). Role names are replaced longest first; replacing `Highlight` before `HighlightedText` produced `#314f78edtext` and the `QCssParser::parseHexColor: Unknown color name` warnings at startup. Keep the longest-first sort if you add roles.

## 13.4 Settings page interplay

`AppearanceSettingsPage` live-previews styles and palettes, which would fight the theme. While "Claude" is selected the style combo, custom colours and tab bar colours are disabled; the theme is applied or removed on **Save** (`ClaudeTheme::Apply()` / `ClaudeTheme::Remove(style)`), and re-applied on **Cancel**. `Appearance::LoadCustomPaletteColors` does nothing while the theme is active.
